# HeightFall 设计基线

## 定位

5v5 方格 MOBA，规则和节奏以 Dota 2 为参照。地图由方格组成，所有技能都以格子为目标。技能可以实时改变地形高度，这是核心玩法。单局目标时长 30–40 分钟。

## 美术风格

纯白简约，整体是几何风格：场景和所有单位都是白色，全部由基础几何体构成，没有贴图，只用纯色材质。建筑按阵营上色，敌我靠血条区分。

### 场景

- 每个格子是一根独立的方柱，相邻柱子之间留 0.06 m 的窄缝，柱子一直延伸到地面下 2 m 的底板，地图边缘看上去像一块有厚度的沙盘。顶面受光照，接收单位和建筑的影子；侧面和底板用不受光照的平涂色，侧面按朝向固定变暗 3%–12%，缝隙只是一道浅线。每级高度 0.2 m，高度差靠分层设色和侧面明暗分辨。
- 地面按高度分层设色：每级高度一种颜色，低处偏冷，高处偏暖偏深，相差 1 级也能分清；兵线和坡道比同高度的地面略深一点（见色板）。升降动画中颜色随高度渐变。
- 泉水不放模型，只把它占的 5×5 格子染成淡淡的阵营色。
- 高调柔光：以天空光为主，主光从左上方照射，阴影浅而柔和。
- 不在视野内的区域蒙上一层浅灰，区域内的单位隐藏。

### 单位与建筑

- 英雄由 3–6 个基础几何体（立方体、圆柱、圆锥、球、棱柱）组合而成，每个英雄的轮廓都不同，高约 1.3 m。
- 小兵用五种正多面体（柏拉图立体）：

| 小兵 | 形状 | 高度 |
|---|---|---|
| 近战兵 | 正六面体（立方体） | 0.7 m |
| 中程兵 | 正四面体 | 0.8 m |
| 远程兵 | 正八面体 | 0.8 m |
| 炮车兵 | 正十二面体 | 0.9 m |
| 超级兵 | 正二十面体 | 1.1 m |

- 建筑由多个几何体组合而成，底面都是与格子对齐的方形：
  - 防御塔：白色方形底座、阵营色方柱塔身、白色檐口，顶上悬浮一个缓慢旋转的发光正八面体。塔身上的白环数量等于层级减一。
  - 兵营：白色底座、阵营色主殿、四角深色立柱、白色三棱柱屋顶。
  - 基地核心：两层白色台基、四角阵营色方尖碑，上方悬浮缓慢旋转的发光星形八面体（两个正四面体交叠）。
- 建筑按阵营上色：「岭」用冷色，「渊」用暖色；同一阵营里，塔从 T1 到 T4 由浅到深，兵营和基地核心各用一种颜色（见色板）。
- 首领是大型截角二十面体（足球形）。
- 每个单位和建筑头顶都有血条，血条颜色区分敌我：己方天青色，敌方赭红色，中立深灰色。

### 特效

- 技能特效由纯色几何粒子（小立方体、四面体碎片、光束）、贴地的方形冲击波和格子闪光组成，颜色用施法者的队伍色。
- 直线技能：格子从施法者脚下依次亮起并溅出碎块；穿云另有一道光束飞到尽头。范围技能：方形冲击波从中心扩散，范围内格子同时亮起。
- 抬升和下陷：升起 0.25 秒，越过目标后回弹；下陷 0.3 秒，砸下去再弹两下；效果结束时 0.5 秒缓慢回落。直线上的格子依次隆起。单位随地面一起升降。
- 闪现：起点和落点同时炸开碎块。腾跃：起跳处一圈冲击波，落地时再一圈并震屏。
- 受击：单位叠一层橙红闪光，并被压扁再弹回；近战攻击时攻击者朝目标冲一下。死亡：碎成几何碎块，建筑倒塌时碎块用阵营色并震屏。眩晕：头顶三个金色小四面体绕圈。
- 伤害数字：只显示与英雄有关的伤害，技能伤害字号更大；己方受到的伤害为赭红色，其余为深灰色。
- 大招和大面积地形变化会震屏。
- 技能范围全部用格子高亮表示：己方技能为天青色，敌方技能为赭红色。延迟生效的技能在生效前显示落点格子。

### UI

布局参照主流 MOBA，风格与场景一致：白底、细线条、线条风格的几何图标。战斗 HUD 以图标、数字和状态为主；商店显示装备名称、属性、价格及买卖反馈。桌面、触屏和网页复用同一套 Godot 控件，输入与布局根据设备调整。

- 顶部中央：双方击杀数夹着游戏时间，己方在左，旁边的小方块是队伍色。
- 右上角：当前英雄的击杀 / 阵亡（× 图标）和补刀 / 反补（方块图标）。
- 左上角：仅显示金币和商店入口；桌面点击或触屏轻触即可打开装备商店。英雄的生命条、法力条和等级移到头顶，黑底金边等级圆徽章位于血条左侧，两端显示一致。
- 桌面右下角：圆形技能按钮。Q W E R 排成一行，大招按钮稍大；召唤师技能在左边，回城和恢复位于其左上方。按钮内是几何图标，左下角标出快捷键。
- 触屏右下角：技能环绕大号普攻按钮，召唤师、回城和恢复位于左侧；技能按钮隐藏字母快捷键。左下角是移动摇杆，镜头跟随当前英雄。横竖屏分别调整布局和缩放，避开屏幕安全区。
- 两种技能布局共用状态绘制：英雄技能外圈是分段等级环，冷却显示扇形遮罩和倒计时，回城和恢复显示进度，有技能点时出现「+」，操作失败时外圈短暂闪红。站在己方泉水里可打开召唤师技能选单；桌面排成一行，触屏排成两行图标。
- 中文使用本地 Noto Sans CJK SC 子集作为原字体的 fallback，拉丁文字继续使用原字体。来源、字符集重建与 OFL 许可证保存在 `game/fonts/`，字体随 Godot 资源导出。

## 相机

- 透视相机，俯角 60°，垂直视场角 35°（窄视角，观感接近等距视角）。
- 朝向正北，格子边线与屏幕的横纵方向对齐。
- 默认可视范围约 26×15 格；滚轮缩放 ±20%。
- 镜头默认锁定，平滑跟随当前英雄。解锁后可以按住中键拖动地图，或用方向键、鼠标贴边平移；按住空格时临时回到英雄身上。

## 操作

### 键盘与鼠标

桌面保留以下操作，网页在使用键盘和鼠标时也适用：

| 操作 | 按键 |
|---|---|
| 移动 | 右键点地面，自动寻路 |
| 攻击 | 右键点敌方单位；右键点血量低于一半的己方小兵为反补 |
| 释放技能 | 指向技能按住 Q / W / E / R（英雄技能）或 F（召唤师技能）显示范围，松开即朝鼠标位置释放；或点击技能按钮进入瞄准，左键确认；无目标技能按下即用 |
| 回城 / 恢复 | B / V，或点击对应按钮 |
| 更换召唤师技能 | 站在己方泉水里点召唤师技能按钮，在弹出的一排图标中选择 |
| 取消释放 | 瞄准时按右键或 Esc；施法前摇中按 S 或右键移动 |
| 学习技能 | 1 / 2 / 3 / 4 分别对应 Q / W / E / R，或点击技能按钮上的「+」 |
| 停止 | S |
| 锁定 / 解锁镜头 | Y |
| 移动镜头 | 按住中键拖动，或方向键、鼠标贴边 |
| 回到英雄 | 按住空格 |
| 打开商店 | 点击左上角金币入口；选择装备后购买，选择已有装备格后出售 |
| 切换测试英雄 | Tab，或点击商店中的英雄切换入口 |

F1 升级和 Ctrl + 左键 / 右键对 3×3 地形的抬高 / 降低仍是开发测试操作。

### 触屏

- 左摇杆控制移动；右侧普攻按钮可按住，选择附近可攻击目标。
- 按住指向技能图标进入瞄准，拖动调整方向和距离，松开该手指施放。拖到取消区后松开，或点击取消图标，可放弃施法；无目标技能按下即用。
- 左手移动和右手技能瞄准可同时进行，每个控件只处理自己捕获的触点。额外手指不会抢走已有瞄准；失焦、暂停、系统触摸取消、英雄切换与布局变化会清理手势。
- 点「+」学习技能，点回城 / 恢复图标执行对应操作；在泉水内点召唤师图标后选择更换。触屏按钮显示图标和状态，不显示 Q / W / E / R / F / B / V 字母。
- 轻触左上角金币入口打开商店，在商店内选择、购买、出售或切换测试英雄。商店打开时隐藏摇杆和技能栏，阻止地图与镜头输入；关闭后恢复，游戏模拟继续运行。

### 商店与装备

两端共用一个 Godot 商店和 `HeightFall.Sim` 的真实买卖规则。目录提供全部 / 攻击 / 防御 / 移动分类，当前有 9 件装备：

- 攻击：短剑、战斧、长矛。
- 防御：生命石、能量石、护盾、重甲。
- 移动：轻靴、疾行靴。

每位英雄有 6 格背包，每件装备占一格，同种装备可重复购买。英雄可在任意位置购买，死亡期间也可整理装备；购买需要足够金币和空位，扣费后属性立即生效。界面显示装备价格与属性，金币不足或背包满时显示模拟层返回的原因。装备定义位于 `src/HeightFall.Sim/Content/Items.cs`，校验和买卖位于 `World.Shop.cs`。

选择已有装备后出售，返还原价的 70%（整数金币向下取整）。购买和出售都会重新计算生命、法力、攻击、护甲和移速；生命 / 法力保留当前占上限的比例，买卖不会让阵亡英雄复活。UI 直接调用相同的模拟层规则，网页与桌面的数值结果一致。

| 参数 | 值 |

| 点目标技能 | 射程内的任意格子 |
| 逻辑帧率 | 30 Hz |

## 高度系统

高度取整数 0–7。

| 高度 | 用途 |
|---|---|
| 0 | 深坑（只由技能产生） |
| 1 | 河道 |
| 2 | 地面：兵线、野区 |
| 3 | 坡道、野区台地 |
| 4 | 基地高台 |
| 6 | 岩壁（比地面高 4 级，从地面上不去） |
| 7 | 地图边界 |

高崖和深坑是这个游戏的核心：从下面上不去，从上面可以跳下来，但落地会眩晕。

规则：

1. **移动**：向上只能走高度差 ≤ 1 的格子，2 级及以上上不去；向下任何落差都能走。斜走时，两侧的格子也都必须能从起点走进去，否则禁止斜穿。
2. **坠落**：向下走，或脚下格子在一次变化中突然下沉，落差 2 级及以上时坠落，落地眩晕：落差 2 级 0.4 秒，每多 1 级加 0.3 秒，最多 1.2 秒。画面上单位先迈出崖边再加速掉落，落地扬起尘土。
3. **抬起**：单位脚下的格子升高时，单位随格子一起升高，不受影响；之后可以随时跳下去，代价是坠落眩晕。
4. **深坑**：坑壁比坑底高 2 级及以上时，坑里的单位走不出来，要等地面回升。
5. **回落**：地形效果到期时格子用 0.5 秒缓慢回落，站在上面的单位随之降下，不算坠落。
6. **寻路**：坠落眩晕计入寻路代价，平时绕坡道，直接跳下明显更快时才跳。
7. **视野**：以单位为圆心的圆形范围，不受高度影响。
8. **弹道**：直线飞行的技能和投射物会被比施法者高 2 级或以上的格子挡住；抛物线和空中类技能可以越过地形。
9. **改变高度**：技能产生的是带持续时间的临时修正值。同一格的多个修正值相加，结果限制在 0–7 之间，到期后逐个撤销。
10. **固定格**：建筑占地格和泉水区域的高度固定不变。
11. **位移落点**：位移技能的落点必须是未被占用的格子，落点高度受技能限制（最多比施法者高几级），超出时预览变红、无法释放。地面瞬移落到低 2 级以上的地方，与走下高崖一样坠落；空中位移落地不算坠落。

## 地图

- 128×128 格，约为 Dota 2 地图的 85%。最外圈 4 格是边界（高度 7），可活动区域为 120×120。
- 坐标原点在左下角，x 向东，y 向北。
- 「岭」的基地在西南角，「渊」的基地在东北角。地图既关于中心点对称，也关于对角线 x = y 对称，因此双方、上下两路完全对称。下文只列「岭」方坐标，「渊」方坐标为 (127 − x, 127 − y)。

攻击顺序：

## 兵线

- 每 30 秒出一波，0:00 出第一波。
- 每波 3 个近战兵、1 个远程兵，外加 1 个特殊兵：
  - 4:00 前是中程兵；
  - 4:00 起换成炮车兵；
  - 某一路的兵营被摧毁后，敌方在该路的炮车兵换成超级兵。
- 每 7.5 分钟，小兵属性提升一次。
- 小兵移速 3 格/秒，索敌范围 5 格。
- 小兵索敌优先级：刚攻击过己方英雄的敌方英雄 > 小兵和建筑 > 其他英雄。防御塔同理，只是不打建筑。
- 补刀：完成最后一击获得金钱。
- 反补：己方小兵血量低于 50% 时可被己方攻击；被反补的小兵只给敌方英雄一半经验。

## 技术基线

- 引擎：Godot 4 .NET 版，使用 C#。
- 逻辑层是独立的纯 C# 类库，不依赖 Godot，以 30 Hz 固定帧推进，可以单独做单元测试；Godot 层负责渲染、输入和音效。
- 控制、HUD 和商店在 Godot 游戏层共用，金币、装备、属性和买卖校验由纯 C# 模拟层结算。桌面与网页使用同一场景和游戏逻辑。
- Windows、Linux、macOS、Android、iOS 和 Web 是源代码移植目标。目前已有 Windows 游戏运行和自编 Godot WebGPU 网页构建的实际验证；仓库只有 WebGPU 导出预设，其他平台的 SDK、模板、配置和设备验证仍需准备。源码共用不表示已具备六平台发布配置或产物。
- 本文中的所有数值都放进数据表，由逻辑层读取。
- 联机采用权威服务器：客户端只发送指令，服务器结算后广播状态。
